# Privacy Policy — मात्रा मित्र (Matra Mitra)

_Last updated: 2026-09-26_

मात्रा मित्र (Matra Mitra) is an offline Hindi-learning app for children.
It does not collect, store, or share any personal data, and it is safe for
use by children.

- No account, sign-in, or personal information is required to use the app.
- The app works fully offline. It does not use the internet and cannot send
  any data anywhere.
- Speech is produced on-device by Android's own text-to-speech engine.
  Nothing you say to the device or hear from it is recorded, stored, or
  transmitted.
- Any learning progress the app keeps is stored only in the app's local
  storage on your own device and is never uploaded.
- The app does not request any sensitive permissions and does not use
  analytics, advertising, or third-party trackers of any kind.

If you have questions about this policy, contact vaibhavr.crly@cag.gov.in.

## Hosting this page for the Play Console

Google Play requires a live, public URL for your privacy policy (Play
Console → App content → Privacy policy, and the Data safety section). The
simplest way to get one for a GitHub repo:

1. In the repo, go to **Settings → Pages**, set **Source** to the `main`
   branch (`/root`), and save.
2. GitHub Pages builds the site with Jekyll, which turns this file into a
   page automatically at:
   `https://<your-github-username>.github.io/MatraMitra-Android/PRIVACY.html`
3. Paste that URL into the Play Console fields above. (If Pages isn't set
   up yet, the direct GitHub link — `https://github.com/<user>/MatraMitra-Android/blob/main/PRIVACY.md`
   — also works as a stand-in public page.)
